# 🏡 SHS Corretora de Imóveis — Projeto Integrador | Faculdade Unipan

Este repositório apresenta o resultado do projeto integrador desenvolvido por cinco estudantes da **Faculdade Unipan**, com foco na criação de um **site institucional para a SHS Corretora de Imóveis**. O projeto reúne um catálogo dinâmico de imóveis e uma página de detalhes personalizada, refletindo a identidade elegante, moderna e profissional da empresa.

## 📸 Visão Geral

O site da SHS foi projetado com uma abordagem **clean, responsiva e sofisticada**, com foco na experiência do usuário e na apresentação visual dos imóveis. Ele contempla:

- **Página inicial com carrossel de destaques**
- **Catálogo de imóveis carregado dinamicamente via JSON**
- **Página de detalhes com informações completas do imóvel**
- **Seção institucional com a história da corretora**
- **Design moderno e acessível**

---

## 👨‍💻 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias front-end modernas e de fácil manutenção:

| Tecnologia     | Finalidade                                  |
|----------------|----------------------------------------------|
| **HTML5**      | Estrutura da aplicação                       |
| **CSS3**       | Estilização e layout responsivo              |
| **JavaScript** | Lógica dinâmica de carregamento dos imóveis  |
| **JSON**       | Estrutura dos dados dos imóveis              |
| **SwiperJS**   | Carrosséis de imagens modernos e responsivos |
| **Lucide Icons** | Representação visual com ícones modernos |

---

## 🧩 Funcionalidades Principais

- ✅ Listagem dinâmica de imóveis a partir de um arquivo `db.json`
- ✅ Página de detalhes com informações completas (localização, valor, descrição, etc.)
- ✅ Design elegante e alinhado à identidade da corretora
- ✅ Carrosséis de imagens com **SwiperJS**
- ✅ Ícones visuais com **Lucide Icons**
- ✅ Código organizado e modular, com foco em manutenção e escalabilidade futura

---

## 📄 Detalhes Técnicos

- O carregamento dos imóveis é feito por **JavaScript puro**, buscando os dados no `db.json` e renderizando dinamicamente na página inicial.
- A navegação entre os imóveis e suas respectivas páginas de detalhes é feita via **URL query (`?id=...`)**, garantindo leveza e simplicidade.
- O projeto foi desenvolvido com foco em **boas práticas de semântica HTML** e **separação de responsabilidades** entre HTML, CSS e JS.
